# Silent Error Detector 🔍

An AI-powered code error detector for beginners built with:

- FastAPI + MongoDB (Backend)
- React + Monaco Editor (Frontend)
- OpenAI GPT-4 (AI Analysis)

## Features

- Write and run Python code in the browser
- Detects runtime and logical errors
- AI explains errors in beginner-friendly language
- User authentication with JWT

## How to Run

1. Start backend: `uvicorn main:app --port 8001`
2. Start frontend: `npm run dev`
3. Open http://localhost:5173
